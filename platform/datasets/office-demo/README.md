# office-demo dataset

The simulated office used by the Smart Office demo. Loaded into a tenant with
`make dataset TENANT=<key> DATASET=office-demo`; the simulator reads the same files.

| File                 | Content                                                                                               | Schema (`@platform/shared/dataset`) |
| -------------------- | ----------------------------------------------------------------------------------------------------- | ----------------------------------- |
| `world.json`         | site, building, floors, zones, rooms (with floor-plan geometry in a 1000×600 viewBox), desks, devices | `WorldSchema`                       |
| `personas.json`      | employee behaviour profiles (arrive, leave, meetings)                                                 | `PersonasSchema`                    |
| `tenants/<key>.json` | tenant identity, hostname, brand, tariff, 24 employees with desks and personas                        | `TenantDatasetSchema`               |
| `brands/<key>/`      | `logo.svg`, `favicon.svg`, `theme.json`                                                               | referenced from the tenant file     |

The JSON files are generated by `generate.mjs` (run `node datasets/office-demo/generate.mjs datasets/office-demo`
from `platform/`); edit the generator rather than the JSON so geometry and device positions stay consistent.
Marker positions keep the top 48 px of each room free for the code, name and live power readout.

Laptops are not listed in `world.json`; one is created per employee as `LAPTOP-<employeeCode>`.
Device access tokens are `<tenantKey>-<deviceCode>` so the dataset is reproducible. All names are fictional.
