# Migrations

Generated by `pnpm --filter @platform/api generate` from `src/db/schema/*.ts`; applied by the API on
start (`node dist/server.js`) as the `app_admin` role, or manually with `pnpm --filter @platform/api migrate`.

`0000_init.sql` was hand-edited after generation: it creates the `app` (RLS-enforced) and `app_admin`
(BYPASSRLS) roles without passwords and grants table privileges. Deployments set the passwords
(compose does it in the postgres init script); tests connecting as a superuser must run
`ALTER ROLE app PASSWORD '...'` themselves. Future migrations must not be edited after they have been applied.
